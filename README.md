## 📌 About

**REST API Security Lab** is a learning project focused on understanding how REST APIs can be tested, secured, and documented.

The goal is to build a controlled environment for exploring authentication, authorization, input validation, and other API security concepts.

> 🚧 This repository is currently in the planning and documentation stage. Features and testing results will be added as development progresses.

## 🎯 Objectives

* Understand REST API security fundamentals.
* Explore authentication and authorization weaknesses.
* Learn to identify and document API vulnerabilities.
* Practice secure API design and remediation.
* Build practical experience with Python and API testing tools.

## 🔍 Planned Security Topics

| Topic                                    | Focus                                            |
| ---------------------------------------- | ------------------------------------------------ |
| Broken Object Level Authorization (BOLA) | Access control between user-owned resources      |
| Authentication                           | Login flows, tokens, and session handling        |
| JWT Security                             | Token validation and configuration               |
| Input Validation                         | Handling unexpected or malicious input           |
| Security Misconfiguration                | Debug settings, headers, and exposed information |
| Rate Limiting                            | Abuse prevention and request throttling          |
